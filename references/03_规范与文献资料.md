## 二、逐篇拆解：全文论证怎样成立

### P01 郭志京：特别规范如何改变一般规则的推导方法

**研究争点**：为什么公司对外担保的一系列问题经过长期争论仍难形成一致认识？对外担保规则与普通公司规则、普通民法交易规则有何区别？

**作者的中心论点（概括）**：公司对外担保是一种具有特殊规制价值和规制方式的规则体系；需要从其涉及的公司利益与交易相对人预期出发，区分意思形成限制、内部规则的对外效力，再讨论规范对象、合同效力和责任承担，而不能孤立适用一般原则。

**文章实际论证链**：

1. **不是简单列举旧说，而是解释争议何以长期存在**：引言指出，以往研究容易把规范对象、规范性质、规范效力和违法后果割裂处理；作者以“规则特殊性未被充分识别”定位根因（PDF第1—2页）。
2. **先分析规制对象与利益结构**：公司为他人债务担保有其利益双面性，故需要辨认公司财产安全、内部治理和相对人合理交易预期之间的张力（第2—3页）。
3. **论证特别规制方式，而非直接跳到效力结论**：讨论决议形成过程的限制以及章程、内部决议对外效力的有限扩张（第3—6页）。
4. **将“规范特殊性”转化为后果检验标准**：分别考察规范对象、性质、对外效力及可能的合同法连接方式，审查不同学说在实践中的后果（第6—10页）。
5. **在统一框架下处理具体法律后果**：再进入公司决议效力、担保合同效力、责任承担等问题（第10—12页）。

**可迁移写法**：`争议的结构性根因 → 特别事实/规范性质 → 规制方式 → 解释后果`。尤其值得学习的是**不直接由规则条文推出合同责任**，而先解释其规制对象和效力机制。

**适合调用的场景**：研究“某项规范为何对平台施加与传统企业不同的义务”时，先证明不同规制的法律理由，再确定具体义务和责任；论证“内部规则是否产生对外效果”时，必须找到规范连接机制。

**不可照搬**：该文发表于2014年，以当时法律和司法理解为背景；不得将其对公司担保效力的具体法条解释当作2026年现行规则。文章的核心价值在于论证顺序，而不是旧法上的实质结论。

**建议回看原文**：PDF第1—2页（争议定位）、第3—6页（规制方式）、第9—12页（后果推导）。

### P02 任江、陈超：制度方案必须经过“可行性”这一关

**研究争点**：现行成年意定监护中的监督机制如何完善，公证机构能否承担核心监督功能？

**作者的中心论点（概括）**：应结合私力与公力监督形成双轨结构，利用公证机构的既有规范基础和实践优势，安排事前、事中、事后的具体监督职责。

**文章实际论证链**：

1. **制度起点**：从《民法典》成年意定监护制度及监护人的监督不足切入，说明现行撤销监护资格机制为何无法替代完整的监督体系（第1—3页）。
2. **比较方案**：把单轨监督（私力、公力）与双轨监督作为可比较的路径，评价各自的成本、信息与干预程度（第3—4页）。
3. **本土化论证**：转向公证介入的**规范基础、实践基础、相对优势**，避免把比较法结论直接当成中国法上的制度权限（第4—6页）。
4. **职责分解**：沿监督时间分为事前、事中、事后，并分别论证机构的协议审查、过程监督和争议处理等职责（第6—7页）。
5. **结论**：回收“为什么这个机构、为什么这种路径、怎样实施”的问题（第7页）。

**可迁移写法**：`规范缺口 → 制度备选项 → 适合本国法律与实践的理由 → 谁在何阶段做什么 → 如何救济`。

**适合调用的场景**：论证程序性义务、平台内部申诉、第三方监管、行业协商与纠纷解决机制。

**不可照搬**：方案可行性证明不等于已有明确法定授权。比较法经验、行政便利和“有助于监管”都不能单独构成法定义务来源。

**建议回看原文**：PDF第2—4页（规范缺陷与比较）、第4—6页（可行性）、第6—7页（职责设计）。

### P03 任江：怎样严密回应“这个研究概念根本无必要”的质疑

**研究争点**：“新兴权利”是否具有独立的理论解释价值，抑或不过是既有权利的新情境应用、道德权利的法律化？

**作者的中心论点（概括）**：既有权利的动态解释并不能穷尽新社会生产关系中权利义务结构的形成；研究新兴权利，应说明其社会生成基础、规范证成机制以及从司法确认到立法转化的路径。

**文章实际论证链**：

1. **全面梳理既有概念路线**：不是只列代表学者，而是按解释逻辑整理不同的新兴权利概念（第2—6页）。
2. **选最强反对命题进行正面回应**：先承认既有权利具有动态适用能力，再指出它不足以解释新的权利内容、义务结构和救济方式如何生成（第6—11页）。
3. **补上社会发生基础**：通过生产方式与个体自由空间的变化，解释“为什么会出现这一法律问题”，而不满足于概念逻辑的自我循环（第11—14页）。
4. **进入法律化过程**：把司法确认和立法转化作为不同阶段，讨论特定利益的可诉性以及法律形式的形成（第14—19页）。
5. **回收理论任务**：从概念、发生基础、司法与立法之间的层次关系总结研究所得（第19页起）。

**可迁移写法**：`厘清已有观点 → 精确识别反对论证的前提 → 承认合理部分 → 论证剩余解释缺口 → 构造新概念的独立功能 → 回归规范运作`。

**特别值得学习的句段逻辑**：反驳不是“某说忽视新形势”，而是先指出旧说能说明的范围，再说明它**无法解释的具体法律对象**。这能显著减少没有论证的“创新性宣称”。

**适合调用的场景**：讨论算法取中是否有独立的规范内涵、能否还原为既有劳动基准或算法透明义务等问题。**这里仅是提问方向，不预先断定它具有独立原则地位**。

**不可照搬**：并非所有新词都应被“证成为新权利/新原则”。必须先考察现有法律概念是否已经足以解释争议。

**建议回看原文**：PDF第2—6页（学说分类）、第6—11页（否定论回应）、第11—19页（发生基础与转化）。

### P04 王轶、包丁裕睿：由判例归纳“司法在怎样解释法律”

**研究争点**：夫妻共同债务的不同认定与清偿方案，如何体现法院在规范构成要件和利益风险之间作出的价值选择？

**资料和方法**：作者按说明中的检索条件考察司法解释实施后一段时期的863篇裁判文书（摘要与PDF第2页）；按规范要件分别分析，不把不同问题简单合并成“支持/不支持”。

**文章实际论证链**：

1. **先交代问题属性和样本口径**：区分民法中的事实、价值、解释选择等问题，并说明案例来源、期间与取样边界（第1—3页）。
2. **依规范结构而非统计结果组织章节**：依次研究双方合意、家庭日常生活需要、共同生活或共同生产经营、清偿规则（第3—17页）。
3. **对每个构成要件列出司法解释方案**：例如，在“共同意思表示”下区分明示、默示、沉默；在“日常生活需要”下区分金额与用途标准、举证责任（第4—8页）。
4. **用“小结与分析”把经验差异转化为规范问题**：说明各解释为何体现不同价值取向、是否符合体系与证明责任规则，而不是停留在案例分布（第5、8、14、17页）。
5. **结论返回制度操作**：从概念清理、实体与程序互动、典型利益冲突中的价值判断指引提出可继续研究的方向（第18页）。

**可迁移写法**：`法条关键词 → 事实变量与裁判方案 → 案例组之间的关键分歧 → 解释技术 → 法理评价 → 认定因素及证明规则`。

**段落上的可学习模式**：先概括某类判决的具体解释标准，再呈现不同裁判，再指出二者以不同方式分配事实认定风险，最后讨论哪个标准与规范目的协调。

**适合调用的场景**：以小规模判决书样本讨论“认定要件”“举证责任”“法官隐含的价值判断”。尤其要学习每个子节末的**解释评估**，不能仅仿照文章做频数统计。

**不可照搬**：样本设计和数据结论属于夫妻债务问题，既不能迁移为平台纠纷经验事实，也不能把863篇的规模或原方法当作任何课题的强制要求。使用自己的案例样本必须另行记录取样偏差、法院层级、裁判时间和规范适用时点。

**建议回看原文**：PDF第1—3页（方法）、第4—8页（要件分析）、第9—14页（不同解释标准）、第17—18页（规范评判）。

### P05 罗寰昕：从定性争议走向法定基准及其余留的自治空间

**研究争点**：隐私政策究竟属于合同约定、法定保护基准的说明，还是具有其他规范功能？在个人信息公法保护发展后，其作用如何变化？

**作者的中心论点（概括）**：从告知同意模式下的合同定性争论出发，隐私政策随法定个人信息保护基准的确立而转为一种最低标准的说明和合规工具；但单纯书面合规易流于形式，仍须讨论超越最低基准的信任形成、具体场景与自治承诺。

**文章实际论证链**：

1. **先公平呈现争议双方**：隐私政策为何曾被视为合同，以及对此提出的“真实合意”和救济不足等批评（第2—6页）。
2. **通过规范与案例改变问题框架**：将讨论从“是否合同”转向“法定基准如何影响其内容与效力”，并以查阅复制权相关案例观察实际法律适用（第6—10页）。
3. **对新模式再次作功能检验**：法定基准虽然能够保障最低权利，但书面政策可能被形式化，且抽象规则对丰富的处理场景存在覆盖限度（第10—12页）。
4. **回应识别出的具体不足**：在场景融入、隐私承诺的保护义务及民主参与等方面提出进一步路径（第12—16页）。

**可迁移写法**：`旧定性及其解释力 → 新规范如何改变制度性质 → 新模式解决什么问题、仍缺什么 → 针对缺口提出新义务或程序`。

**重点理解**：法定的**最低义务**与企业在合法范围内作出的**更高层次自治承诺**并不等同；两类义务的产生依据、内容与可执行性须分别论证。

**适合调用的场景**：写“平台算法规则：法定标准与企业自治规则的关系”“最低劳动保障要求如何具体化”“算法透明与实质保护之间的关系”。注意这些只是**方法上的适配**。

**不可照搬**：个人信息保护法中的权利请求、信任/承诺理论不自动产生劳动法上的义务；跨部门移用应补充适用规范及差异说明。

**建议回看原文**：PDF第2—6页（合同争议）、第6—10页（法定基准）、第10—12页（形式化问题）、第12—16页（后续机制）。

### P06 罗寰昕：算法控制如何转化为劳动法上的分析变量

**研究争点**：平台借算法实施的劳动管理如何接受从属性检验；在平台与配送合作商共同参与劳动管理时，如何讨论劳动关系认定和劳动权益保护责任？

**作者的中心论点（概括）**：算法控制提供重新观察劳动管理事实的视角；从人格、经济、组织从属性分别判断劳动关系；专送骑手可能面临共同雇主和传统单一雇主识别模式的不适配，故作者主张在关注劳动关系认定的同时，进一步转向具体劳动权利保障，并从控制关键劳动条件的事实论证平台的“守门人”责任。

**文章实际论证链**：

1. **研究对象的视角切换**：从“平台”这种用工载体转向“算法控制”这种可描述、可评价的劳动管理事实（第2—4页）。
2. **将宽泛的控制拆成可检验要素**：人格从属性下考察指示与服从、监督与惩罚、考核与薪酬；经济从属性下考察经济依赖、生产资料等；组织从属性关注平台究竟只是中介还是实质参与劳动组织（第4—9页）。
3. **汇总之后再进入典型场景**：先形成从属性要件清单，随后以“专送骑手”考察平台与配送合作商的协同管理（第9—10页）。
4. **将主体身份困难转化为义务配置问题**：单一雇主识别难以完整回应实际劳动管理过程，作者由此转向具体劳动权利和共同参与者的责任问题（第10—12页）。
5. **为新主体义务寻找专门理由**：利用平台对关键劳动条件、合作商筛选监督等事项的控制，提出平台“守门人”地位，并进一步讨论合规、监督、程序民主和司法救济等具体内容（第12—14页）。
6. **在结语回扣更一般的规范问题**：从特定平台劳动形态推广到新技术改变劳动管理方式后的劳动权益保障问题（第15页）。

**最有价值的论证操作**：

- **先事实、后法律**：平台的算法如何给出指令、设置考核与薪酬安排，必须先作为事实命题查明。
- **先要件、后结论**：人格、经济、组织从属性不是同一句“算法控制很强”的三个同义名称。
- **先责任基础、后责任内容**：即便赞成让平台承担某类义务，也还需要分别论证其法源、可控事项、义务触发条件和法律后果。
- **明确“转向”理由**：研究问题由“劳动关系归谁”转到“劳动权益由谁承担保障义务”，并非任意换话题，而是回应既有认定框架不能解决的责任缺口。

**适合调用的场景**：算法劳动管理、平台与合作企业主体义务分配、平台是否成为特定劳动法/监管义务主体。

**关键风险**：作者关于“守门人责任”及劳动权益保障的方案是**学说主张**，不能未经现行法分析就写成司法已普遍采纳的法定责任。文中引用的2021年政策及地方材料须按研究时点重新核查。

### P07 劳东燕：如何对一个“看似无懈可击”的理论做教义学检讨

**研究争点**：以法益衡量作为违法阻却的一般原理，是否足以解释不同正当化事由及其法律后果？

**作者的中心论点（概括）**：将利益衡量等同于狭义的法益衡量，易忽略制度利益、法律体系的既有价值安排与法治国基础价值；单一原理在不同正当化事由中会出现体系性矛盾，故需要对利益衡量的使用加以方法论约束。

**文章实际论证链**：

1. **强问题意识**：以既有原理对正当防卫、紧急避险、被害人同意等案例可能得出反直觉结论为起点，提出“这个一般原理本身是否足够”的问题（第1—2页）。
2. **概念区分与起源追溯**：首先梳理“利益衡量”与“法益衡量”为何在特定理论结构中被混同（第2页起）。
3. **跨制度反例检验**：将同一原理应用于多个内在结构不同的正当化事由，检查其前提能否一致贯彻；如出现“要获得可接受结论就临时调整权重”的状况，反推理论不自洽（约第7—15页）。
4. **提升批判层次**：不仅指出具体结果不妥，还分析其方法论问题及对立法判断、解释者主观性的影响（约第16—21页）。
5. **给出有约束的新框架**：讨论制度利益、法治国基础利益等层次及其在解释中的次序，强调利益衡量不能脱离规范体系（约第22—31页）。
6. **结论**：明确反对将该理论当作统一实体根据，并重新定位利益衡量这一方法（末页）。

**最值得迁移的“反证法”**：

```text
某理论T声称能够统一解释A、B、C三种法律情形。
→ 精确提出T在各情形中应遵守的前提和推理步骤。
→ 选取T最难处理的边界情形，不仅选择容易支持T的案例。
→ 如T必须临时引入与初始前提不兼容的解释，定位真正的概念/方法缺陷。
→ 新框架必须说明为什么不再出现相同缺陷，并服从既有规范约束。
```

**适合调用的场景**：当论文需要证明既有“保护劳动者利益”“利益衡量”“控制力决定责任”等直观判断不足以作为独立规则时，可学习其反证结构。

**不可照搬**：不能把刑法违法阻却理论及法益层级直接移用于劳动法或个人信息保护；跨部门使用的仅是**测试学说一致性的方法**。该文原PDF存在特殊字符，**逐字引述、脚注页码应人工对照PDF版面**。

**建议回看原文**：PDF第1—2页（问题定位）、第9—12页（反例）、第17—20页（方法论）、第23—30页（替代性框架）。

### P08 税兵：用一个解释工具贯通纷乱的民法问题

**研究争点**：民事主体死亡后，法律为什么仍保护其相关利益；死者利益与生者权利如何在法技术上发生连接？

**作者的中心论点（概括）**：身后损害问题需要在传统民法的主体、权利、利益概念框架内得到解释；作者借法律拟制分析不同利益及其救济模式，主张通过更符合体系要求的法益保护路径处理利益冲突。

**文章实际论证链**：

1. **以司法上的矛盾启动理论问题**：从身后损害裁判中主体与权利认定不一的现象，追问“救济的法律连接机制是什么”（第1—3页）。
2. **回到基本概念做拆分**：讨论人格、人格权、人格利益是否可以分离，说明不能直接以“自然人死亡”为全部结论的终点（约第4—6页）。
3. **引入解释性工具**：利用法律拟制将不同类型的身后利益与生者的诉讼、救济安排建立关系（约第6—10页）。
4. **辨析工具的适用边界**：不是说所有利益都可以任意拟制；需按照延伸、转换等不同结构及制度体系，说明何者可被保护（第8—10页）。
5. **与民法体系相协调**：从既有民事主体制度、利益位阶和司法救济等方面说明何种保护模式更具体系一致性（第10—14页）。
6. **保留未竟议题**：指出尚有立法技术与保护期限等问题，避免将宏大理论包装为所有实践问题的最终答案（第14页附近）。

**可迁移写法**：`裁判矛盾 → 基础概念冲突 → 寻找法技术连接机制 → 利益类型化 → 法体系与救济检验`。

**适合调用的场景**：在新类型行为出现时，研究是否需要创设新权利、借助既有权利还是通过义务/法益保护实现救济。

**不可照搬**：该文以当时民法典编纂和相关既有法为背景，**绝不能据此把旧时立法建议描述为当下法**；论文中关于法律拟制与保护模式的取舍也属于作者论证，不是通行法定结论。文本抽取质量较弱，严格核对原版。

**建议回看原文**：PDF第1—3页（司法问题）、第5—10页（基本范畴与拟制）、第11—14页（保护模式）。

### P09 宁园：为什么“先分层”有时比“先提出对策”更有解释力

**研究争点**：数据财产权益的归属与利用为何不能只从初始控制或单个交易关系出发？如何配置不同环节的权益？

**作者的中心论点（概括）**：有必要区分数据生产与数据流通，分别讨论初始控制权和后续利用权；既有赋权进路与关系进路各强调一端，二层结构能够回应控制秩序与流通效率的不同要求。

**文章实际论证链**：

1. **一开始就精确收窄研究对象**：从广义数据权益中区分出数据财产权益，确定本文究竟解决什么、暂不解决什么（第1—3页）。
2. **不满足于两派学说并列，而是揭示其真实交点**：分析赋权进路与关系进路分别重视数据控制端和流通端，指出两者各自难以独立解决全过程问题（第3—5页）。
3. **先说明双层结构的必要性**：将“生产—流通”作为反映实际法律问题的分界，而非仅作修辞（第3—5页）。
4. **第一层逐步论证**：在生产端讨论数据控制权，界定数据生产及相关主体，并区分“数据来源贡献”“数字劳动”等概念，以限制权利主体的泛化（第5—13页）。
5. **第二层逐步论证**：在流通端区分数据利用权的意定配置与法定配置，进一步讨论法定限制、私主体和公共部门的区别（第13—18页）。
6. **余论收束体系关系**：将两层配置放回更大范围的数据权益保护体系中，而不让前述分层被误解为对全部法律利益的一揽子回答（第18页）。

**最值得迁移的组织方法**：

```text
先问：目前争论是否在回答同一个层次的问题？
若否：提出具有现实和法律理由的分层标准。
第一层：主体与基础权能如何形成。
第二层：权能如何转移、限制、分享或产生相应义务。
层间：通过统一的法律目的和适用条件维持体系一致。
```

**适合调用的场景**：研究“规范适用范围—义务具体内容—程序保障”的不同层次，以及平台、合作企业、劳动者之间的义务安排；特别适合防止一个章节同时混写主体、义务和救济。

**不可照搬**：数据财产权益配置中的权利结构、劳动赋权理论及具体政策判断不自动适用于劳动法；真正能迁移的是“为什么分层、如何说明分层规范后果”的方法。

**建议回看原文**：PDF第1—5页（问题清理与构架）、第5—13页（概念边界）、第13—18页（分类规则）。

## 三、横向比较：9篇文章共享了哪些有效“论证动作”

### 动作A：把“社会问题”转换成可回答的法律命题

- P01不是问“公司担保应当怎样完善”，而是追问为何规范对象、性质和效力一直纠缠。
- P03不是问“新兴权利很重要吗”，而是问它是否具有不能被既有权利解释替代的独立功能。
- P06不是只说“算法侵害劳动者权益”，而是将算法事实放进从属性要件并追踪责任缺口。
- P08不是只讨论“是否保护死者”，而是追问死者利益与生者诉权之间的法律技术。

**执行规则**：引言最后必须写出一个可回答的问题和拟证明的判断。禁止停在“很重要，因此需要研究”。

### 动作B：先证明判断标准，后用判断标准处理场景

- P04先分“共同意思”“共同生活”等规范要素，再把法院解释按照这些要素分类。
- P06先建立人格、经济、组织从属性要素，再分析专送骑手及多主体困境。
- P09先说明“生产—流通”的分层必要性，再提出各层配置规则。

**执行规则**：不能因为已经知道结论才倒推出“符合标准”的理由。分类变量应当能在具体资料中独立查明。

### 动作C：反对观点不是仪式性“然而”，而是推进论证的工具

- P03承认旧概念有动态解释力，但指出其尚未解释的部分。
- P05承认法定基准有实际保护作用，再评估纯书面合规的局限。
- P07把理论置于多个相异场景，发现统一解释框架的内在冲突。

**执行规则**：任何反对意见都须能够改变解释选择或界定适用边界；如果它对结论没有影响，不必占独立段落。

### 动作D：制度/责任结论必须同时回答“为什么”和“如何”

- P01以特别规制方式支撑对法律效力的讨论。
- P02先证明公证机构的比较优势和可行性，再拆分职责。
- P05先处理“法律基准与自治承诺”，再谈未来保护义务。
- P06先论证算法事实和控制地位，再提出平台特定义务的学理方案。
- P09先处理控制权形成，再处理利用权配置。

**执行规则**：仅有“该企业应承担责任”不是完整结论；至少进一步回答责任基础、承担主体、义务内容、触发条件与救济/责任后果。

### 动作E：警惕从“很好”直接跳到“法律上成立”

- P07提醒以一般价值判断替代既定法的制度安排，会产生解释者主观性的问题。
- P04说明裁判实践隐含价值选择，但规范评价仍需要法律依据。
- P02表明制度可行性和权力/权限的法律基础是不同论证环节。

**执行规则**：始终标明一个结论的性质：`现行法明确规定` / `本文对现行法的解释` / `学说提出的可能方案` / `立法论建议`。

## 六、供以后写作时直接查询的“论证资源卡”

### R01 概念是否具有独立理论价值

- **借鉴**：P03 的“先承认旧概念能解释什么，再证明它解释不了什么”；P09 的“界定论文只处理哪一种权益”。
- **问题清单**：这一新概念是否改变义务主体、法定要件、行为标准或法律后果？既有概念能否以较小成本解释相同问题？如无额外规范功能，为什么要引入新概念？
- **禁忌**：不因制度名称出现新词就断定出现新权利或新原则。

### R02 从抽象规范推导具体义务

- **借鉴**：P05 的“最低法律基准—私主体承诺—执行限制”；P01 的“规范对象—规制方式—法律后果”。
- **问题清单**：规范要保护什么？义务约束谁？规范使用何种法技术（禁止、要求、条件、程序、责任）？能否在不创设新权限的情况下实现？
- **禁忌**：不得把政策性倡议直接写成可诉的确定义务。

### R03 多主体分工与义务边界

- **借鉴**：P06 的实际控制、从属性和共同雇主问题；P02 的阶段性职责分工。
- **问题清单**：不同主体分别决定、执行、监督什么事项？是否存在权力与义务脱节？谁有能力防范具体风险？义务基础是法定身份还是特定行为控制？何种共同履行或分别履行情形应区分？
- **禁忌**：不应将“控制越强，当然责任越重”当成不需规范证明的一般公式。

### R04 理论检讨与边界案例

- **借鉴**：P07 多制度反证；P03 对否定论的命题式回应。
- **问题清单**：竞争解释最有说服力的理由是什么？它在何种边界案例失败？失败是事实差异、文本限制还是原理矛盾？替代解释能否处理旧说解释得好的情形？
- **禁忌**：不要为了反驳而歪曲对方观点，也不应无限扩大“理论冲突”。

### R05 裁判材料支持规范论证

- **借鉴**：P04“按条文要件分类—观察解释方案—由实证回到规范评价”。
- **问题清单**：裁判差异对应哪一法律要件？有无法院层级、时间和事实结构差异？是法官解释不同还是证据不同？结论需要改变解释、证明责任还是规则设计？
- **禁忌**：多数裁判结果不等于最佳解释；样本内比例不得无条件推广到总体。

### R06 实践困境怎样引出制度方案

- **借鉴**：P02“规范缺失—比较—可行性—具体职责”；P05“新基准的形式化问题—针对性回应”。
- **问题清单**：现行制度到底缺少权力、程序、义务还是救济？提议的新方案解决哪一具体缺口？与其他机制是否重复？如何处理成本和权利限制？
- **禁忌**：不得只按“事前、事中、事后”罗列抽象建议而不讨论各阶段法定权限。

## 七、引用和写作调用协议（供GPT使用）

### 1. 引用定位规则

在正文需要某篇文献时，先用编号找到来源，例如：

- `P06，PDF第9—13页` → 找到罗寰昕关于从属性梳理、共同雇主困境和“守门人”责任的论证。
- `P09，PDF第2—5页` → 找到宁园关于对象界定和二层分析框架的论证。
- `P07，PDF第17—30页` → 找到劳东燕关于利益衡量方法论和解释限制的讨论。

**注意**：这些为检索定位提示，不是可以直接提交期刊的正式脚注。正式脚注需核对纸本/电子版期刊页码、著录规范及准确文本。

### 2. 作者观点与写作技巧的隔离

写作时必须分清：

```text
【文献事实】P06作者论证平台“守门人”责任。
【论证观察】P06先识别算法管理事实，再讨论从属性，再进入义务配置问题。
【可迁移方法】写其他平台义务题目，可使用“事实—要件—义务依据—边界”顺序。
【禁止跃迁】不得因此断言现行法已确立一项统一的“平台守门人劳动法责任”。
```

### 3. 不编造的最低要求

- 未在原PDF或权威规范原文中确认的法律条文、裁判事实、引文和页码，一律标为 `[待核实]`。
- 禁止虚构九篇论文未讨论的作者观点、所谓“主流学说”或引注。
- 旧论文的理论分析与其引用的当年法条必须分别记录；法律修订后应重新解释。
- 方法论跨领域借鉴，先说明相似的**法律问题结构**，再检验部门法差异；不能直接搬用实体规则。
- 写作规范只约束表达与推理程序，研究结论必须从**具体题目的法源与研究材料**独立获得。

### 4. 下次上传新资料时如何更新本库

对新增文章统一增加以下字段：

```text
文献编号：P10（依次递增）
完整著录：作者、文章名、刊物、年度与期次（有原文页码再加）
论文性质：规范解释 / 概念证成 / 体系建构 / 比较法 / 裁判实证等
核心争点：一句话
中心命题：一句话
全文链条：4—7个“因为什么，所以进入下一步”的节点
最关键的三个推理段：PDF定位 + 对论证动作的概括
可迁移写法：需要满足什么前提
不可照搬的实体结论：涉及什么特殊法源或事实
法规范线索：规范全称、条款、版本待核状态
```

## 八、对当前文献包的综合判断

1. **足够建立一套有操作性的“规范法学写作规范”**。9篇覆盖了概念澄清、理论证成、规范解释、权益/义务配置、实证辅助、利益衡量和制度设计，方法样式有差异，适合做横向对照。
2. **不适合提取一个所谓“统一的顶刊语气”**。P07的强批判、P04的裁判材料分析、P02的方案设计和P09的分层配置解决不同任务；不应把全部章节强行写成相同模样。
3. **已经具备有限的平台劳动直接文献**。P06与平台算法控制和主体责任最相关，P05可提供法定义务与私主体自治关系的**类比方法**；但它们不是算法取中规范问题的完整文献基础。
4. **现阶段最值得利用的是“论证的中间步骤”**。每次研究应优先问：一个结论在事实—法条—概念—解释—责任之间有没有跳过关键环节。语言上的坚定只能建立在这些中间步骤已被证明的前提下。

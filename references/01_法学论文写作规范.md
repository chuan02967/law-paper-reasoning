# 法学规范分析论文写作规范（基于9篇范文提炼）

> **用途**：供 GPT-6 High 在撰写、重写、审查法学学术论文时调用；重点提升“论证成立”而非仅改善“语言像论文”。  
> **研究适配**：规范解释、法律性质与概念界定、义务/责任配置、制度建构及“少量裁判材料辅助规范分析”的论文。  
> **来源范围**：用户上传的《文献基础.rar》中的9篇文章。文献逐篇分析、具体PDF页码及规范线索见 `03_规范与文献资料.md`。  
> **原则**：借鉴论证技法，不照搬原文句式、观点、章节名称或文献引证。以下规范是对范文的综合归纳，**不是**9位作者共同认可的统一方法。

---

## 一、最优先执行的12条写作规则

1. **命题先行，而非材料先行**。写作前用一至两句话说清本文要证明的法律判断，而不是仅说“研究某个问题”。
2. **一个章节完成一个论证任务**。每章都必须改变读者对核心命题的理解：澄清前提、确立依据、完成推导、处理反例或确定后果。删除只承担“介绍现状”的冗余章节。
3. **论证需要推理桥梁**。不能从“现实中平台具有影响力”直接跳到“平台依法承担某项义务”；须分别证明规范依据、规范目的、义务主体资格、行为关联、义务内容与边界。
4. **先辨问题属性，再选方法**。事实认定、规范解释、价值判断、立法建议不能混写成一个命题。尤其不能把“应然制度设计”伪装成“现行法当然结论”。
5. **概念界定服务于争点**。只定义会改变法律结论的概念；每个区分应说明其规范后果，而非仅罗列学术定义。
6. **反对观点要“击中理由”**。先以最合理的版本呈现竞争解释，再指出其在规范文义、体系、目的、解释后果或边界案例中的具体不足；不能只说“存在局限”。
7. **以类型化处理差异**。共同事实结构可以统一分析，关键法律要素不同的情形必须分类；类型划分标准应当可检验，而不是将结论重新包装为分类名称。
8. **价值衡量受规范约束**。将规则已经实现的价值选择、制度利益及法体系中的限制纳入分析；不能把“公平”“效率”“保护弱者”当作独立且充分的法律依据。
9. **段首先给出可检验的判断**。段落随后给出法条/学说/裁判事实、解释步骤及必要限制；段尾交代该段如何推进下一步论证。
10. **避免防御性空话，但保留真实的限定**。“可能、一定程度上、值得关注、有待研究”等词仅在证据或规范确有不确定性时使用；不为形式中立而编排正反各半的篇幅。
11. **引注与论证同步**。每条法规范、学说归属、案件事实应能对应原始来源；禁止编造注释、页码、文献、条文内容和判例。
12. **结论须回收核心命题**。结论回答“原问题如何解决、据何理由、适用到何处”，不以“进一步加强监管、完善机制”作为全部结论。

## 二、先决定选用哪一种“全文论证架构”

范文并无唯一正确的结构。以下五种架构仅供按研究问题选取、组合。

### A. 既有理论检讨—规范重构型

**适用**：学界普遍采用某个解释，但无法处理若干典型情形。  
**论证顺序**：准确还原既有理论 → 找到其关键前提 → 用规则体系与反例检验前提 → 说明失败的共同原因 → 提出可操作的替代解释 → 用同一案例群回测。  
**来自**：劳东燕《法益衡量原理的教义学检讨》；任江《新兴权利概念的澄清与法理证成》。

关键：批评必须导出新方案；新方案须通过原方案无法通过的测试。不能为了显示原创性而人为制造“现有研究皆有不足”。

### B. 概念与对象清理—二层/多层配置型

**适用**：研究对象很宽泛，原有争论混淆不同层次或环节。  
**论证顺序**：界定讨论范围 → 精确复述两种竞争路径 → 确认双方实际解决的是不同层次的问题 → 建立具有规范意义的分层标准 → 在各层分别论证权利/义务及例外 → 检验交界处的一致性。  
**来自**：宁园《从数据生产到数据流通：数据财产权益的双层配置方案》；郭志京《中国公司对外担保规则特殊性研究》。

关键：先证明“为什么必须分层”，再展开分层设计。分类不是装饰性的目录工具。

### C. 规范性质辨析—功能变化—义务具体化型

**适用**：同一法律文件、制度或管理机制在不同规制背景下发生功能变化。  
**论证顺序**：提出定性争议 → 检查既有定性的形成条件和救济局限 → 用新规范与典型案例识别功能变化 → 检验新机制的形式化/不足 → 在法定基准之上讨论自治、程序或新义务的具体功能。  
**来自**：罗寰昕《隐私政策的过去、现在和未来：从合同、基准到信任背书》。

关键：后半部分的制度主张须由前半部分证明的功能缺口推导出来；不能因为前述模式有局限，就当然主张另一模式。

### D. 事实控制—构成要件检验—多主体责任型

**适用**：多主体参与同一活动，法律主体识别与实际控制结构不匹配。  
**论证顺序**：识别新事实机制 → 选定相关法规范的要件 → 将事实逐项映射要件 → 以典型劳动形态/交易形态发现责任归属困境 → 区分身份认定问题与义务分配问题 → 提出责任基础、义务清单、适用边界。  
**来自**：罗寰昕《算法控制视域下平台用工劳动关系认定的困境与出路》。

关键：事实上的技术控制、劳动关系认定与特定劳动法义务的承担是三个不同命题，不允许用同一事实跳过各命题之间的法律论证。

### E. 裁判分歧—解释方案—规范性评价型

**适用**：已有判例样本，需要识别司法中隐含的解释选择。  
**论证顺序**：先辨事实、价值与解释问题 → 确定样本口径 → 按规范要件而非判决结果简单分组 → 摆出不同的解释路线及代表案例 → 揭示背后的风险分配与价值取舍 → 结合现行规范检验合理性 → 提炼可操作的裁判要素。  
**来自**：王轶、包丁裕睿《夫妻共同债务的认定与清偿规则实证研究》。

关键：样本数量不能替代法律推理；“多数法院这么做”是实践描述，不是规范正当性的充分证明。

### F. 规范缺口—比较路径—可行性—实施细则型（辅助架构）

**适用**：确实在进行制度设计或解释论与立法论相结合的研究。  
**论证顺序**：定位现行规范缺口 → 对比具有可比性的制度路径 → 提炼本国制度所需的功能条件 → 验证本国法上的权限依据与实践可行性 → 按事前/事中/事后或主体/程序/救济具体化。  
**来自**：任江、陈超《论我国意定监护监督机制的实施进路》。

关键：比较法经验仅提供备选路径，不能直接证明中国现行法上的权限或义务。

## 三、全文逻辑的具体校验方法

### 1. 写作前填充“六格论证卡”

```text
研究争点：一个需要在法律上作判断的精确问题。
中心命题：本文究竟主张何种法律结论。
规范基础：可以引用的现行法律、司法解释、监管规则或可论证的法律原则。
推理中项：从规范基础到结论之间，缺不了哪一步解释或概念区分。
反例与边界：什么情形最可能推翻或者限制中心命题。
规范后果：适用这一解释，将改变主体、行为、证明或救济上的什么结果。
```

如果“规范基础”缺位，先补研究材料，不能借口写作风格直接把“应当”写成“依法”。

### 2. 章节排序以论证依赖关系为准

应问“读者不知道本章结论，能否理解下一章的推理”，而不是“惯例上第二章该写现状”。

- **问题起点**：主导争议的法律判断，不是泛泛的数字经济、社会发展背景。
- **成立前提**：关键概念、规范适用范围、事实结构；仅保留后文真正使用的前提。
- **核心推理**：对主要命题进行规范解释、体系检验和反例检验，允许占用最多篇幅。
- **结论展开**：从已证成的标准推导义务内容、适用场景、责任或程序后果。
- **限度说明**：只讨论足以改变结论的例外、利益冲突和制度制约。

### 3. 章—节—段三个层次须同构

- **章**：回答一个分论点，例如“为什么该主体可能成为特定义务承担者”。
- **节**：解决章内一个必要前提，例如“控制能力能否构成规范意义上的归责依据”。
- **段**：提出一项可独立说明的判断，例如“信息中介身份不足以排除其对特定劳动条件的实质决定”。

每个层次均遵守“命题—理由—检验—本层结论”，但不要求机械地写成固定四段。

## 四、规范分析的八项硬要求

1. **规范识别**：准确区分法律、司法解释、行政法规、部门规章、规范性文件、征求意见稿及学者建议。明确时点与效力，不作降格/升格混用。
2. **保护目的**：说清法规范保护的法益、利益关系与风险分配，而不是直接抽象化为“保障公平”。
3. **解释对象**：锁定具体词项、构成要件、主体要素、行为要素或法律效果，不空谈“精神”。
4. **体系一致**：检验与相邻制度、一般规则、特别规则的关系；若主张特别处理，应证明区别理由。
5. **事实映射**：解释现实行为如何满足或不满足规范要件。不可将事实陈述偷换为规范判断。
6. **相对方案比较**：比较各解释在文本忠实度、体系协调、规则确定性与目的实现上的得失。
7. **边界条件**：检验容易混淆的两种场景，明确何种额外事实足以改变法律结论。
8. **规范后果**：交代由谁履行什么义务，针对何种行为、在何种条件下、以何种方式实现与救济。

### 规范推导不能跨越的三组断层

- **事实权力 ≠ 法定义务**：实际影响或控制行为，是可能触发某项义务的事实理由；仍需证明规范依据及义务范围。
- **身份关系 ≠ 全部义务**：某主体未必被认定为劳动法上的用人单位，并不直接回答其是否因其他法源承担特定义务；反向亦然。
- **价值正当 ≠ 解释合法**：政策上值得实行的方案，未必可以直接通过现行条文解释得到。可将其列为立法论结论。

## 五、从优秀范文提炼的“段落推进法”

下面是**新编的通用写作骨架，不是范文原句**。按争点选择，不是每段都套同一模板。

### 模式1：判断—依据—解释—后果（规范解释段）

```text
[判断] 就X争议而言，关键不在于A的形式名称，而在于B是否满足某项规范要件。
[依据] 某规范将法律效果系于C，其保护目的在于D。
[解释] 因而判断B时，需要查明E与F，而不能仅凭G作结论。
[后果] 据此，在E成立而F不成立的场景中，应区分H与I两种法律效果。
```

必须把变量换成真实、已核实的规范和证据。不能把骨架当作可以凭空生成具体法结论的许可。

### 模式2：学说检讨—问题定位—替代标准（批判段）

```text
[准确复述] 甲说认为判断标准是A，其主要理由为B。
[支持处] 该说能够解释C类情形。
[反例] 但在D类情形中，A会将法律后果E与相邻制度F相冲突。
[原因] 问题并不只是A“保护不充分”，而是其混同了G与H。
[替代] 因此应以I为判断基准；它同时能解释C、D两类情形。
```

这一方法尤其可借鉴劳东燕的“以多个正当化事由检验统一理论”及任江的“对否定论作命题级回应”。

### 模式3：分类—标准—区别后果（类型化段）

```text
[类型界线] X可依据具有规范意义的Y区分为A型与B型。
[分类理由] A型具有要素C，B型则缺少C而具备D。
[规范关联] 该差异对应某规则对E的要求。
[法律后果] 因而两型在义务主体/适用范围/证明程度上应采取不同处理。
[校验] 如果Y无法改变上述法律后果，应重新考虑这一分类是否必要。
```

### 模式4：裁判材料—隐含解释—评价（案例分析段）

```text
[争点] 同一条文的构成要件X存在两种司法理解。
[实证描述] 在已定义的样本中，A类裁判侧重事实Y，B类裁判侧重事实Z。
[法解释] 两类做法分别对应解释路径C与D。
[规范评价] 按规范目的E、体系关系F及证明责任规则G，C/D何者更可取。
[小结] 提炼能供后续案件适用的判断步骤，不以案例数量直接证明法理正确。
```

## 六、学术语言规范：坚定、克制、可追问

### 1. 推荐的命题表达

- “这一争议的实质不是X，而是Y。”——**仅当确已论证X并非核心争点时**使用。
- “X不足以单独证明Y；还须检验Z。”——将限定转化为明确判断标准。
- “A与B的差别在于C，因此二者不能适用同一法律后果。”——以规范要素完成区分。
- “该解释在X场景中成立，但不能扩张至Y场景，原因是Z。”——明确例外的理由。
- “就现行法而言，可得出的结论是A；进一步的B属于立法选择。”——隔离解释论与立法论。

### 2. 清理防御性表达

| 应当警惕的写法 | 实质问题 | 更好的处理方式 |
|---|---|---|
| “随着时代发展，问题日益凸显” | 没有法律争点 | 指出哪一构成要件或主体归属出现适用困难 |
| “学界存在不同观点，值得进一步研究” | 没交代分歧的判断节点 | 说明不同观点对A要件采取什么解释、导致何种结果 |
| “两种观点各有合理性，应予平衡” | 以平衡替代选择 | 指明规范如何预先分配利益，以及何种条件下例外 |
| “平台应当承担相应责任” | 主体、义务、条件不明 | 说明何平台、何行为、何法源、何责任及其触发事实 |
| “似乎、可能、一定程度上”反复出现 | 不必要的判断退让 | 已论证处直接下结论；证据不充分处写明不确定性的具体来源 |
| “从多个维度完善治理机制” | 对策泛化 | 将具体义务、操作程序、违约/违法后果逐项对应 |

**禁止误解**：不应一律删除“可能”“原则上”“一般而言”。当这些词承担要件限定、举证风险、适用范围或学术异议的准确说明时，应当保留。目标是**论断强度与论证强度匹配**。

### 3. 句段节奏

- 一段原则上只有一项中心判断；多个并列判断应拆开或先揭示共同的上位命题。
- 优先使用准确的法律概念与逻辑连接词，不依赖华丽比喻、排比句、层层同义反复制造“学术感”。
- 学说综述不以作者姓名为主线堆砌，而以“争议命题—各说理由—共同盲点/分歧—本文回应”为主线。
- 关键推理在引注之后仍应独立写清：文献是证据和对话对象，不能代替作者本人论证。
- 小节末尾尽可能给出**中间结论**，但无需固定使用“综上所述”。
- 不强迫全部一级标题采用相同字数、相同词性；首先追求标题准确反映论证任务。

## 七、文献、规范和案例的证据使用规则

### 1. 五种句子的引证方式不同

| 句子性质 | 需要何种依据 | 写作注意 |
|---|---|---|
| 现行法陈述 | 官方规范文本，校验版本、生效时间和效力 | 不用旧论文中的转引代替现行法核验 |
| 作者A认为X | A的原文和准确页码 | 不把作者意见写成法定标准或学界共识 |
| 实践中通常发生Y | 可靠调查、裁判样本、平台规则或实证研究 | 不以单一报道推出普遍事实 |
| 依上述规范应认定Z | 本文完整的解释论证 | 不能只在句末添加法条编号就当作证明 |
| 将来应确立Z制度 | 现实缺陷、比较方案、可行性及正当性论证 | 明确是立法/政策建议，不能写成现行要求 |

### 2. 文献使用权重

- **研究材料**：用来确认既有研究的具体观点、学说争议、案例和法律线索。
- **论证范文**：用来学习学术操作，例如反例检验、概念区分、层级配置。
- **规范依据**：指直接核验的适用规范；**任何学术论文均不能替代这一层**。

9篇范文中，算法控制论文与平台义务问题存在直接主题关联；其他论文主要提供论证方法。尤其《公司对外担保规则特殊性研究》（2014）以及早期民法典编纂背景下的文章，不能将当时的法规范表述作为2026年的现行规则。

## 八、写作与审稿分工（推荐流程）

**第一轮：搭建论证架构**。只输出研究争点、中心命题、章—节结构、各节要完成的证明任务、规范材料缺口。此轮不追求文字完成度。

**第二轮：逐节写作**。每次仅生成一个实质性小节。对每一核心判断标明：依赖哪条法律规范、哪条学说或哪份材料；资料不足处以 `[待核实：具体资料]` 标记，不得编造。

**第三轮：针对性审查**。让模型暂时作为严苛同行审稿人，只审最可能导致结论失效的漏洞：规范适用错误、循环论证、类别混淆、未经证明的事实、反例、例外条件。

**第四轮：结构与语言编辑**。在结论已被证明的基础上删除空泛过渡、重复争议介绍与防御性措辞。不得以“语言更坚定”为由提高未经证明的结论强度。

### 审稿时使用的简要检验表

- [ ] 引言结尾是否给出本文将作出的明确法律判断？
- [ ] 每一级标题是否回答一个必要的论证问题？
- [ ] 每个“因此”之前是否有足以推出结论的理由？
- [ ] “应当”到底来自现行法、解释主张还是立法建议？
- [ ] 作者归属与引注是否可以在原文中定位？
- [ ] 是否已处理与中心命题真正冲突的最强反例？
- [ ] “权利/义务/责任/权限/程序/救济”是否被区分？
- [ ] 是否存在仅叙述现状却不服务于中心命题的段落？
- [ ] 关键结论是否具有明确的适用条件和排除条件？
- [ ] 结论章能否逐项回收前文证明过的判断？

## 九、供 GPT-6 High 直接调用的主指令

以下可直接复制到新对话作为**写作规则**，但应同时上传 `03_规范与文献资料.md` 和待写主题的真实规范资料：

```text
你现在承担中国法学规范分析论文的研究与写作工作。

一、写作优先级：法律论证成立 > 问题意识清晰 > 章节逻辑 > 段落连贯 > 表面文风。请以《01_法学论文写作规范.md》中的可迁移方法为规范，以《03_规范与文献资料.md》中的逐篇记录了解各方法的具体来源，不把范文实质结论视作我的研究结论。

二、每次写作先厘清：本节准备证明什么命题；依据何种规范与事实；从依据到结论需要哪一项解释性推理；反例能否成立；结论的适用边界何在。论证不充分时先说明缺口，不凭空补上。

三、不要写成“背景—问题—争议—建议”式流水账。标题反映论证任务，章节按逻辑依赖关系排序。每段围绕一项具体判断，既有观点只在与中心命题有直接关系时展开。

四、避免防御性写作：不因形式上追求中立而刻意弱化有依据的判断，也不安排空泛的正反平衡。限定语必须对应真实的规范、事实或论证限制。反对意见只讨论真正可能推翻命题的理由。

五、严格区分：现行法上的结论、本文主张的解释、立法论建议、范文作者观点和未经证实的待核事实。引注不得虚构，法条须核对文本和时间效力。引用他人观点必须准确注明作者、文献和已核对的页码；缺材料标记待核。

六、先输出“中心命题—分论点—论证依赖—规范依据—材料缺口”表，经确定后逐节写作。完成正文后，分别进行“论证有效性审查”与“语言去空泛化编辑”，不得以润色代替重新论证。

七、不得套用9篇范文的原文措辞或章节结构。模仿的是论证操作，不是文本本身。下文如果给出研究问题或资料，以这些资料为准；不要为了套模型而强改研究问题。
```

### 对GPT的逐段追问

完成一段后，不评价它“像不像顶刊”，只依次问：

1. 该段第一项判断具体是什么？它是否比“问题重要/存在争议”更明确？
2. 为证明该判断引用了何种规范、事实或学说？来源可靠吗？
3. 从这些材料到段落结论之间，哪一句承担了**不能省略的推理功能**？
4. 如果删去其中一句，是否会导致论证断裂？若不会，该句是否只是重复或修饰？
5. 最后一项判断如何使下一段成为**必要的下一步**，而不是仅用“此外”“同时”拼接材料？

当段落不能回答第3、5项时，应当补强推理或调整顺序，而不是单纯润色措辞。

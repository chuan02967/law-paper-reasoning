## 安装与更新

将整个 `law-paper-reasoning` 文件夹放在 `%USERPROFILE%\.agents\skills\` 下，重启 Codex 或刷新可用 Skills。之后在对话中直接调用 `$law-paper-reasoning`。

- **已经安装v1.1**：可从增量更新 ZIP 中取出文件，在本地同名 Skill 目录中覆盖对应文件；请保留 `agents/openai.yaml`。
- **已上传 GitHub 的仓库**：在仓库根目录更新 `SKILL.md`、`README.md` 与 `references/` 文件夹中的四份文件，再提交版本；仓库根目录必须直接出现 `SKILL.md`。
- 上传到 GitHub 不会自动更新电脑里的本地 Skill。克隆过仓库的可在本地 `git pull`，否则手动同步。

## 用法举例

```text
$law-paper-reasoning 请对照我的论文全文起草一段约300字的中文摘要，
参考 04 的不同摘要路径，直接写出争点、法律结论和关键论据，
并检查摘要是否提出了正文尚未证成的观点。
```

```text
$law-paper-reasoning 请检查当前论文是否把政策必要性直接当成法定义务依据，
对法律效果重新分类，并检查不同理论是否确实回答了不同的必要子问题。
```

## 资料边界与著作权

10篇范文仅作为**写作方法的研究材料**；此 Skill 不包含原始论文 PDF 的全文，也不是某一课题的现行法律规范数据库。引用时须回看原文、核对法条版本及页码。公开仓库时不要未经授权上传范文PDF全文或大段复制原文。

## 版本发布检查

每次新增范文或修改规则后，应当核对：`SKILL.md` 与参考文件是否一致；`CHANGELOG.md` 是否有新版本条目及准确的文件清单；`README.md` 的版本号、目录结构和安装说明是否更新；全量包和增量包是否都包含最新版本日志。

本次由 v1.2 升级 v1.2.1，只需**新增 `CHANGELOG.md` 并替换 `README.md`、`SKILL.md`**；不用重传四份 `references` 文件。

# law-paper-reasoning

面向中国法学学术论文的 Codex Skill：论证逻辑、规范分析、文献综述、学术史梳理、起草和审稿。

## 文件结构

```text
law-paper-reasoning/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── 01_法学论文写作规范.md
    ├── 02_法学文献综述写作规范.md
    └── 03_规范与文献资料.md
```

- **01**：全文结构、法律推理、论证审查、学术语言和去防御性写法。
- **02**：9篇范文的研究现状/学说整理方法、五种综述架构和写作审查。
- **03**：9篇范文全文论证的逐篇拆解与 PDF 页码索引。

## 安装

将整个 `law-paper-reasoning` 目录放到用户级 Skill 目录 `%USERPROFILE%\.agents\skills\` 中。调用 `$law-paper-reasoning`。

## 示例

```text
$law-paper-reasoning 请依据我提供的论文全文和参考文献，先逐篇建立观点证据卡，
再按真实学说争点组织研究现状。区分已有观点、现有研究未解决的具体问题和本文定位，
不要按作者姓名堆砌，也不要编造引注。
```

## 使用边界

此仓库保存的是**写作方法与九篇范文的论证分析**，并非任意研究主题的完整文献数据库或现行法库。写作“算法取中”等具体论文时，须补充该课题的真实法律规范与参考文献。引证时回看原论文及有效法版本。
